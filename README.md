# 💰 SaaS Subscription Simulator

Simule faturamento, custos e lucro de um SaaS em reais conforme sua base de usuários cresce.
Cinco parâmetros, recálculo instantâneo, gráfico interativo. Tudo roda no navegador, nada é salvo.

## Rodar

```sh
npm install
npm run dev
```

## Deploy (Cloudflare Pages)

```sh
npm run deploy
```

Stack: Vite, Preact, Tailwind CSS v4.
